# Anime.js Official Documentation Summary

## Overview

Anime.js adalah JavaScript animation engine yang powerful dan lightweight untuk membuat animasi pada web. Versi terbaru adalah v4.0.0 yang membawa banyak perbaikan dan fitur baru.

## Key Features

- **Lightweight**: Ukuran kecil untuk performa optimal
- **Powerful API**: Mendukung berbagai jenis animasi
- **WAAPI Support**: Dapat menggunakan Web Animation API untuk hardware acceleration
- **Flexible**: Mendukung CSS, DOM, SVG, dan JavaScript objects
- **Timeline**: Untuk mengatur sequence animasi
- **Draggable**: Untuk drag-and-drop functionality
- **Scroll-triggered**: Untuk animasi berdasarkan scroll position

## Main Modules

1. **animate()** - Fungsi utama untuk membuat animasi
2. **createTimeline()** - Untuk mengatur sequence animasi
3. **createAnimatable()** - Untuk values yang sering berubah
4. **createDraggable()** - Untuk drag-and-drop
5. **createTimer()** - Untuk timed callbacks
6. **stagger()** - Untuk animasi beruntun
7. **splitText()** - Untuk animasi text
